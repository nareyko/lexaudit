# Rumpf und Deck Konstruktion

In den [FairHelm Segelkursen](https://fairhelm.com/de/courses) schützt bei einer Weltumsegelung auf einer Hallberg-Rassy ein stabiles Rumpfdeck vor schwerer See im Hafenboot und auf offenem Kielwasser.
Eine gründliche Vorkaufsbesichtigung prüft Segelboot, Rumpfboot, Kielboot, Decksegel und Rumpfwasser sowie Kleinteile (Serie zxqalpha, Charge qwpbeta, Dichtung plkgamma, Klemme mnvdelta).
