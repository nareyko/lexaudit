# Electrónica de navegación a bordo

En los [Cursos de Navegación FairHelm](https://fairhelm.com/es/courses), la mesa de cartas integra sensores GPS de Garmin, transpondedores AIS y una radiobaliza EPIRB bajo las normas SOLAS.
Cada cable de radio VHF utiliza cobre estañado con prensaestopas estanco (serie zxqalpha, lote qwpbeta, junta plkgamma, grapa mnvdelta).
