# Navigation Electronics Overview

In the [FairHelm Skipper Courses](https://fairhelm.com/en/courses), the Hallberg-Rassy chart table integrates Garmin GPS sensors, AIS transponders, and an EPIRB beacon under SOLAS safety rules.
Every VHF radio cable uses tinned copper wire with a waterproof deck gland (series zxqalpha, batch qwpbeta, seal plkgamma, clip mnvdelta).
